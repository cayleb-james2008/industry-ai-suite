# Frozen quality bar

1. **Preservation:** suite and portfolio baselines are named by commit; the approved dark home, lab, cases, web résumé, PDF, ten receipts, and five witnessed AI samples retain their evidence meaning. No status is silently upgraded.
2. **Ten distinct jobs:** every product has a documented input contract, functioning local review path with success, invalid, unavailable, and permission-denied states, task-specific computation, evidence and human handoff. A generic form that only reprints input fails.
3. **Boundary:** raw private input is not logged, stored, sent externally, or substituted with fixture/public data. Workbench remains numeric-loopback with origin and token checks, caps, content-type checks, and denial behavior. Self-asserted ownership is labeled unverified.
4. **AI:** where claimed, an actual model call uses a free authorized local route, exact cited evidence, bounded output, and independent transport witness. Where no safe/model-worthy contribution is present, say AI not run. None of this certifies a full enterprise job.
5. **Verification:** full test suite plus failure/security tests pass; each of ten local journeys is exercised through browser and backend on labelled safe representative input. An independent code/security/design review inspects the resulting changes. Live published files and recorded lab journeys are checked after release.
6. **Truth:** final per-product report separates implemented engineering, fixture-backed checks, real source/model evidence, and missing enterprise proof. If real records or authority are absent, full-job verdict remains `UNVERIFIED` with the minimal exact input needed to change it. No applications or external messages are sent.

This bar is frozen before implementation. Repair work must preserve or strengthen it.
