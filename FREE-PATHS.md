# Free paths for all ten products

Checked 2026-09-26. These are the working, read-only or local paths in this repository. None needs a paid API. A public source proves only the named public slice; a local import proves only what the supplied rows let the processor calculate. Neither turns an organization job into a verified deployment.

Run the local workbench with `python3 -m webapp.server --port 18340` and open `http://127.0.0.1:18340/`. For any product, **Organization bundle · local only** accepts a permitted, de-identified JSON export or loads an invented safe example. [ENTERPRISE-INPUTS.md](ENTERPRISE-INPUTS.md) gives the ten field sets. LedgerBridge and ChainWatch also accept bounded local CSV rows. The [hosted lab](https://cayleb-james2008.github.io/agentic-resume/lab/) replays dated receipts and makes no fresh source request.

| Product | Free working path | What still blocks the complete organization job |
|---|---|---|
| LedgerBridge | [Treasury FiscalData](https://fiscaldata.treasury.gov/api-documentation/) public cash rows; local ledger/bank CSV or JSON review. | Finance-controlled, complete ledger and bank exports plus reviewer and posting authority. Federal cash is not company cash. |
| MarketBrief | [World Bank Indicators API](https://datahelpdesk.worldbank.org/knowledgebase/articles/889392-about-the-indicators-api-documentation) for annual U.S. GDP; local licensed report extracts. | Actual company or instrument research, rights, release timing, and independent analyst judgment. GDP is macro context only. |
| ChainWatch | Local, authorized, watch-only EVM observations in CSV or JSON; no chain request, wallet key, or transfer. | Address ownership, a permitted EVM observation source and sampling history, and treasury escalation authority. The earlier Mempool candidate serves **Bitcoin**, so it cannot populate this EVM review; its hosted terms were also unverified. |
| BacktestGuard | World Bank GDP observation-year chronology check; local experiment records with dataset hashes and release dates. | Real experiment lineage, labels, holdout history, and source availability times. GDP chronology is not a backtest. |
| ReplyCraft | [Federal Register](https://www.federalregister.gov/developers/documentation/api/v1) metadata plus direct [GovInfo](https://www.govinfo.gov/content/pkg/FR-2026-09-18/html/2026-19222.htm) public rule text for a labeled sample; local case/consent/policy import. | A genuine, consent-authorized case, approved policy, and agent review. No message is sent. |
| HandoffHub | The same identity-matched public OPM text for a cited handoff; local knowledge/role/owner import. | Permission-scoped internal knowledge, authenticated grants, and an accountable owner. |
| SentinelDesk | [CISA KEV](https://www.cisa.gov/resources-tools/resources/kev-catalog) public vulnerability context; local alerts/assets/threat import. | Genuine organization alerts, inventory, applicability, and responder authority. A catalog CVE is not an incident. |
| SearchLift | Fixed read of the owned public portfolio page; local permitted HTML-page import. | Editorial ownership and any actual ranking or traffic measurement. An HTML audit does not prove SEO impact. |
| PipelineRelay | [GitHub REST](https://docs.github.com/en/rest/repos/repos#get-a-repository) public repository metadata; local account/consent import. | Genuine CRM context, access, consent, and accountable account owner. A repository is not a sales lead. |
| OnboardPath | Federal Register metadata plus identity-matched GovInfo public OPM text; local request/policy/role import. | Applicable employer policy, authenticated employee records, and HR approval. Public rules are not employee guidance. |

The official public routes in this table require no paid key in this implementation. Treasury [permits reuse of its public data](https://fiscaldata.treasury.gov/api-documentation/); [CISA's KEV license is CC0](https://github.com/cisagov/kev-data/blob/develop/LICENSE); the World Bank Indicators API says its v2 endpoints [do not require authentication](https://datahelpdesk.worldbank.org/knowledgebase/articles/889392-about-the-indicators-api-documentation), while the specific GDP dataset page is checked for `CC BY-4.0` on each live read. Federal Register's [API documentation](https://www.federalregister.gov/developers/documentation/api/v1) describes its public API; the suite uses direct public GovInfo document HTML, not GovInfo's separate key-based API. GitHub permits unauthenticated public REST reads with a [60 requests/hour primary limit](https://docs.github.com/en/rest/using-the-rest-api/rate-limits-for-the-rest-api), subject to additional limits. Source availability, license and age checks remain fail-closed; a 403/429 or missing terms does not trigger a stale fixture or substitute.

Optional model drafting can use an already available local OpenAI-compatible model server with no provider API key. The five dated source-cited samples in [the witness bundle](evidence/ai-witness-20260926/README.md) are independently witnessed narrow calls. The ten organization-import processors remain deterministic; a free model, synthetic example, or public API cannot create missing private records, consent, or authority. All ten full jobs remain **UNVERIFIED** until those inputs and reviews exist.
